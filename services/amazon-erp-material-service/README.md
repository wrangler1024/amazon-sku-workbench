# ERP 自动建料模块（规划中）

**状态：仅模块集成规划，未实现。** 本目录目前只有文档；没有可运行服务、依赖包、API、数据库迁移、页面入口或部署配置。现有组件版本保持不变。

拟定模块标识：`erp-materials`；目录：`services/amazon-erp-material-service`。它负责把已通过选品的商品资料整理为建料草稿，经运营核对后创建或复用领星产品，并读回核验、回填结果。无需等待文案、制图或刊登完成。

## 职责边界

| 层次 | 规划职责 |
|---|---|
| 工作台入口 | 在现有产品资料页提供“领星建料”入口；复用当前商品和资料，不另造一套商品录入页面 |
| 本模块 | 建料草稿、单位换算、复用决策、确认快照、执行步骤、失败恢复和结果追踪 |
| 领星适配 | 产品查询/写入、图片处理、分类与人员映射；凭证和供应商接口差异留在服务端 |
| 现有评审/编辑服务 | 提供选品状态、资料版本、资产引用、身份和数据范围；不承担领星写入细节 |
| 飞书适配 | 将核验后的结果投影到现有ERP字段，最终可由独立系统存储替代 |

独立模块是代码和领域边界，并不要求首期新增一台服务器。未来实现时可先复用现有任务队列、审计与运行资源；若需独立进程，再确定部署方式。本轮不引入新的基础设施。
