状态：模块集成规划，2026-11-10。此目录只保存外部系统能力边界，没有SDK客户端、API调用脚本、企业配置或凭证。

## 官方文档核验与实施待办

| 能力 | 文档层证据 | 实施前仍需确认 |
|---|---|---|
| 产品创建/编辑 | 官方产品接口列出了单位、采购成本、人员、图片和组合组成字段 | 企业写权限；同SKU新增/编辑语义、字段省略/空值语义、类型转换及外部并发冲突 |
| 组合组成 | `group_list`描述子SKU及数量；数量类型为整数 | 子产品前置条件、读回方式、单位口径、成品类型和比例限制 |
| 图片上传 | 图片接口按本地SKU接收图片URL及主图标识 | 图片是否真正可下载；链接有效期；失败、重复上传及图片读回行为 |
| 查询/查重 | 本方案需要精确SKU、详情和映射查询 | 选择并核验具体查询接口及分页，不依赖名称相似自动复用 |
| 分类/人员映射 | 产品写入支持相关标识 | 企业字典查询权限、停用状态、同名歧义以及映射维护责任 |
| 1688配对 | 帮助中心说明了原生普通/高级配对、批量及模板流程 | 可用的公开写入接口未核实，不能宣称已接通自动配对 |
| API鉴权/限流 | 本次只读公开文档 | 凭证管理、刷新、签名、可用权限与实际限流，后续另行验收 |

来源：[添加/编辑本地产品](https://apidoc.lingxing.com/new/api-docs/Product/SetProduct/)、[上传本地产品图片](https://apidoc.lingxing.com/new/api-docs/Product/UploadPictures/)。文档显示具备字段不等于当前企业已授权，也不等于已完成真实接口试验。

1688批量普通配对默认比例需要人工核对；高级配对有同一供应商范围等限制。第一期采用原生操作/官方模板的规划，实际模板格式及适用范围在实施时核验。[1688商品配对](https://www.lingxing.com/help/article/1688Product)

## 适配边界

未来由ERP模块调用服务端适配器，统一处理查询、创建、读回、限流和错误归类。任何长期密钥或访问令牌都不进入前端、Git或业务日志。错误对运营展示具体失败项，对日志保留脱敏请求关联信息。

产品写入只发送运营确认的最小字段集合；关联/复用已有料号时不默认调用编辑接口覆盖原资料。返回成功后仍需查询对账；结果不明确时不能盲目重建。图片是素材交接，采购链接是来源信息，两者均不构成已完成1688配对的证据。
