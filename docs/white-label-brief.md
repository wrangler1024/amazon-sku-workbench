# 白牌图需生成与人工核对

图需生成默认以白牌销售商品为依据。采集文字及图片中的供应商品牌、竞品品牌、店铺和平台标识不构成本品制作要求，也不会被自动替换成店铺品牌。包装判断沿用实际包含物与补充说明；包装不明确时，模型应选择产品细节、组合或使用展示。没有新增包装必填项或独立确认步骤。

后台在调用模型前建立独立资料投影，保留原始采集快照、确认事实和编辑稿。品牌属性只进入检查依据，组成标题中明确的来源品牌从生成投影排除；可能兼作颜色、材质或尺寸的词不机械删除。旧图需作为低优先级参考稿，仅提取符合本品事实与白牌规则的构图偏好。

OpenAI 和 DeepSeek 共用规则。模型可以在独立的 `source_mark_observations` 返回发现的来源标识；该字段保存在生成诊断中，不写进图需 Schema。后台检查正文及每张策划，返回 `brief_review` 提示，不改写结果，不为修正内容追加模型调用。字段及完整 7 张策划的既有结构校验仍有效。

现有候选窗口和编辑页按字段显示疑似问题。运营可直接采用、保存、修改并确认提交，人工确认不会伪造产品事实确认。任务轮询只更新检查元数据及任务状态，不覆盖正在编辑的内容。

默认制作复制文本只包含任务身份与图需，来源链接及补充说明保留在独立资料区。单字段、单张策划、完整图需及历史接管图需共用复制检查：发现已识别标识或平台/链接时提示先修改，不静默删除原文。检查数据未加载时暂不执行制作复制。历史版本和已派单内容不批量改写。

检查属于提示性检测，不代表证明任意视觉 Logo 都已识别；人工仍需核对画面。未确定的品牌、装饰文字和实际包装不能由系统自行确认。本期不提供自动加自有品牌功能。

规则版本、提示词版本和来源人工补充参与生成输入指纹；等待人工补充的采集任务允许显式恢复，但事实、链接、规格或规则变化必须新建生成任务。部署需要同步更新 API 和 model worker；仅更新前端不会改变生成提示词。

版本基线：本分支基于已提交的 bundle 0.3.1，更新为 editor 0.21.2 / api 0.21.1。其他工作区中未提交的功能不包含在该组合。发布记录应另行说明环境；本改动不授权生产发布。
